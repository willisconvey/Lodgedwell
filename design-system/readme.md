# Lodgedwell Design System

The brand and component system behind **lodgedwell.com.au** — online conveyancing
for Victorian buyers and sellers. Warm cream paper, deep eucalypt green, a single
ochre accent, and the real Lodgedwell logo (wordmark + three-chevron roof tile).

**This bundle is generated** from the website repo (`lodgedwell-astro`) by
`design/build.mjs`. `styles.css` here is byte-for-byte the site's stylesheet, so
anything designed with it matches production. Edit the site, rebuild, re-sync.

## Contents

- `styles.css` — the site stylesheet: tokens + every component class.
- `tokens/tokens.css` — just the `:root` token block.
- `assets/` — `lodgedwell-horizontal.svg`, `lodgedwell-reversed.svg` (dark backgrounds),
  `lodgedwell-icon.svg` (tile), `favicon.svg`.
- `guidelines/` — brand, colour, type and spacing cards.
- `components/` — buttons, pills/badges/tabs, cards, lists/forms/FAQ, pricing grid, bands.
- `ui_kits/website/` — header, hero, footer, and the combined marketing-site kit.

## Rules in one breath

Paper `#FAF6EF` canvas, white only for raised cards. Brand green `#1E5C4A`
(hover `#164C3B`, deep `#0E2C22`). Ochre `#E8A13A` for one loud CTA per page.
Plus Jakarta Sans display / Public Sans body / IBM Plex Mono data. Sentence case,
no emoji, Lucide-style 2px line icons. Radii 10 / 16 / 24. Flat surfaces, warm
shadows, calm 120–320ms motion. Never redraw the logo.

## Copy rules

Plain-spoken and reassuring; "you" for the client, "we" for the firm. No
unverifiable claims (no star numbers, settlement counts, invented testimonials).
Real pricing: $1,000 + GST for sale, purchase or transfer, disbursements included;
$330 incl GST on engagement, balance at settlement. Contact is
admin@lodgedwell.com.au only.
